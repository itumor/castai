as agreed yesterday, here are the links:

- Documentation: https://docs.cast.ai/reference/valuerealizationapi_getbaselineparams
- Swagger link: https://api.eu.cast.ai/spec/?urls.primaryName=reporting#/ValueRealizationAPI/ValueRealizationAPI_GetBaselineParams — the value-realization endpoints live in the separate "reporting" spec (`https://api.eu.cast.ai/spec/` → select **reporting** in the dropdown); the main `v1/spec` is the legacy management API.
- Raw OpenAPI spec for tooling/codegen: https://api.eu.cast.ai/spec/reporting/openapi.yaml

Quick facts: `GET /reporting/v1beta/organizations/{organizationId}/clusters/{clusterId}/baseline-params`, authenticate with your API key in the `X-API-Key` header, EU base URL. The reporting spec also exposes baseline `PATCH` (manual override) and `POST .../baseline-params:recalculate` (custom date ranges), which are not yet shown on the docs page.
