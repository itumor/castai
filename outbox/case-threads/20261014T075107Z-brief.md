## Facts verified (2026-10-14, public GETs, no auth)

- Reference page live (HTTP 200): https://docs.cast.ai/reference/valuerealizationapi_getbaselineparams — endpoint `GET /reporting/v1beta/organizations/{organizationId}/clusters/{clusterId}/baseline-params`, auth `X-API-Key` or Bearer JWT, US/EU servers.
- **User correction verified: the ValueRealization API is NOT in the main public spec.** `https://api.cast.ai/v1/spec/openapi.json` (200, 425 paths) contains no `/reporting/*` or ValueRealization paths — only `/v1/cost-reports/clusters/{clusterId}/reporting-capabilities` matched a baseline/reporting grep.
- **The correct Swagger is the multi-spec UI at https://api.cast.ai/spec/** (200; **EU mirror at https://api.eu.cast.ai/spec/** also 200 with the same 18 services + "Legacy API v1"). It loads per-service specs, including `https://api.cast.ai/spec/reporting/openapi.yaml` (200, ~177 KB; **EU copy https://api.eu.cast.ai/spec/reporting/openapi.yaml** is byte-identical) — verified to contain `ValueRealizationAPI_GetBaselineParams` at `/reporting/v1beta/organizations/{organizationId}/clusters/{clusterId}/baseline-params`, plus two operations not shown on the docs page: `PATCH` baseline-params (`UpdateBaselineParams`, manual baseline override) and `POST .../baseline-params:recalculate` (`RecalculateBaselineParams`, custom date ranges). Timeline/report endpoints also present (`:runValueRealizationTimelineReport`, `clusters:runValueRealizationReport`).
- **EU v1 spec `https://api.eu.cast.ai/v1/spec/openapi.json`** (200) — same 425 paths as the US v1 spec; only the `servers` array order differs (EU first). Still NO `/reporting/*` baseline-params — that v1 spec is literally labeled "Legacy API v1" in the EU multi-spec dropdown. (Cosmetic bug noticed: EU spec swaps the "US endpoint"/"EU endpoint" descriptions.)
- Baseline methodology guide live: https://docs.cast.ai/docs/savings-baseline (200) — describes baseline override + recalculation, matching the PATCH/:recalculate operations.
- Response fields confirmed from the page's embedded OpenAPI fragment and the reporting spec: `cpuOverprovisioningFactor`, `memoryOverprovisioningFactor`, `costPerCpuCoreHourly`, `costPerMemoryGibHourly`, `baselinePeriodStartTime/EndTime`, `baselineType` (UNSPECIFIED / CLUSTER_HISTORY / INDUSTRY_AVERAGE / PEER_CLUSTERS / OVERRIDDEN_DATA), `updateTime`.
