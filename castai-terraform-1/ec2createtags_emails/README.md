# EC2 CreateTags Support Emails

This directory holds exported support email threads related to the EC2 `CreateTags` permission issue during CAST AI onboarding.

## Security note

The `.eml` files contain CAST AI API tokens and other sensitive context, so they are kept **local-only** and are not committed to the repository. They are ignored via `../.gitignore`.

## What is preserved here

- The original `.eml` exports remain on disk in this folder.
- Only this `README.md` is tracked in Git so the folder's purpose is documented.\n## Action required

If you have not already, **rotate any CAST AI API tokens** that appear in these emails.
