2.3  Evictor — ownership decision first, then sized values

evictor maxTargetNodesPerCycle: (unset, default 20) → 5 Bounds kube-apiserver pressure per cycle at burst scale; still drains ≈700 nodes/day headroom at 10m cadence. Same sizing table (>500 nodes).
Keep: nodeGracePeriodMinutes: 10, ignorePodDisruptionBudgets: false, dryRun: false, scopedMode: false Safety posture unchanged — Evictor always respects PDBs regardless of mode. ≈95% of nodes are CAST-managed (scoping adds nothing); grace period matches JVM/slow-start workloads. Run kubectl get pdb -A first and fix any minAvailable == replicas PDB before enabling.

2.4  Rebalancing schedules

CHANGEIMPACTWHY
Rebalancing schedules (hourly + postscale) executionConditions.achievedSavingsPercentage: 5 → 2 Micro-wins (2–5% per plan) stop being skipped — small but continuous savings while the on-demand curve stays converged. Every recent skipped/failed integ run traces to achievedSavingsBelowThreshold: instance-to-instance reshuffling is exhausted (integ reshuffles constantly, so per-plan savings are small by design). Real headroom is a mode change — spot and rightsizing — not more cadence.
Decision: keep hourly + postscale schedules enabled; keep minNodes 1, nodeTtlSeconds 300, keepDrainTimeoutNodes: false Fleet hygiene preserved — the schedules are the rollout vehicle for every node-template/config change in this document. Skips are benign (converged), not failures. After the spot-batch and rightsizing changes land, rerun full-cluster rebalances — the converged curve re-opens.

2.5  Hibernation

CHANGEIMPACTWHY
Decision: keep hibernation OFF (no pause/resume schedules on integ) Forfeits a coarse on/off lever (a kronos-style weekend collapse is worth ≈35% of that small cluster’s compute — here it would be speculative). The same money is captured by the spot-batch template + aggressive evictor without an on/off boundary on a shared-VPC cluster. Nightly/weekend test runs are unpredictable and the daily burst calendar is unknown (open question, §4) — a fixed off-window would strand runs or fire mid-burst. PVs also keep billing during hibernation. Revisit only when a test calendar exists; hibernation remains the recommendation for kronos (pilot) and stays off helios (prod) by design.
